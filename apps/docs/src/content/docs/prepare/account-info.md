:::tip[这一页是给运营看的]
这是**每个人各做一次**的准备工作。照着填完发给管理员，管理员把你加进授权名单后，你才能绑定账号。
:::

## 为什么要提供这些

Meta（Facebook / Instagram）的开发者应用在**开发模式**下，
**只有被加进应用角色名单的账号**才能完成授权、发出的帖子才对外可见。

管理员需要你的 **Facebook 用户名或数字 ID** 才能在后台搜到你并加进名单。
这是平台机制，不是内部流程 —— 详见 [Meta 开发者准备 · 授权名单](/prepare/meta-developer/#把成员加入授权名单必做否则运营绑不上号)。

:::danger[永远不需要提供密码]
整个流程只要主页链接、用户名、数字 ID。**任何人向你索要社媒账号密码或验证码，都是异常，请直接拒绝并上报。**
授权是你自己在平台官方页面登录完成的，管理员不经手。
:::

## 复制这张表填好发给管理员

```text
【控制台账号申请】
姓名：
工作邮箱：              （用来登录控制台）
负责市场 / 语言：        例：id（印尼）、ja（日本）

【Facebook】
个人主页链接：           例：https://www.facebook.com/zhangsan.123
Facebook 用户名：        例：zhangsan.123
Facebook 数字 ID：       例：100012345678901
要发帖的主页(Page)名称：
我在该主页的角色：        管理员 / 编辑 / 其他

【Instagram】
IG 用户名：              例：@mycompany_id
已切换为专业号：          是 / 否
已关联上面那个 FB 主页：   是 / 否

【X】
X 用户名：               例：@mycompany_id
```

## 各项怎么查

### Facebook 个人主页链接

**电脑上**：登录 Facebook → 点右上角头像 → 进入个人主页 → 复制浏览器地址栏的完整地址。

**手机 App 上**：进入个人主页 → 右上角「⋯」→「复制链接」。

### Facebook 用户名

就是个人主页链接里 `facebook.com/` **后面**那一段：

```
https://www.facebook.com/zhangsan.123
                         ^^^^^^^^^^^^  ← 这就是用户名
```

:::caution[链接里是一串数字怎么办]
如果你的链接长这样 `facebook.com/profile.php?id=100012345678901`，
说明你**还没设置用户名**。那串数字就是[数字 ID](#facebook-数字-id)，直接把它给管理员就行。
也可以去「设置 → 账号中心 → 个人详细信息」设一个用户名，方便以后使用。
:::

### Facebook 数字 ID

用户名可能重复或被改掉，**数字 ID 永不变**，所以两个都提供最稳妥。

**方法一（最简单）**：如果主页链接里已经带 `profile.php?id=` 后跟一串数字，那就是它。

**方法二**：在 Facebook 里打开 **设置和隐私 → 设置 → 账号中心 → 个人详细信息**，页面中可看到账号标识信息。

**方法三**：搜索引擎搜 "facebook id finder"，把主页链接贴进去查（第三方工具，只贴**公开主页链接**，不要输入任何密码）。

:::note[发给管理员时两个都给]
用户名 + 数字 ID 都发过去，管理员用哪个能搜到就用哪个，省一轮来回。
:::

### Instagram 切换为专业号

**这一步必须你自己做，管理员做不了。**

1. 打开 Instagram App → 进入**自己的主页**
2. 右上角 **☰** → **设置和隐私**
3. 找到 **账户类型和工具** → **切换为专业账号**
4. 选 **商务** 或 **创作者**（都可以）
5. 按引导**关联到你的 Facebook 主页** ← 这一步别跳过

:::caution[为什么必须关联 Facebook 主页]
本系统按 Postiz 的 **「走 Facebook 主页」方案**接入 Instagram，
**IG 必须关联一个 Facebook 主页**才能拿到发帖权限。
没关联的话，授权流程走完也选不到 IG 账号。
:::

**怎么自查切成功了**：进入自己的 IG 主页，能看到 **「专业主页」/「洞察」** 入口就是成功了。

## 发完之后：你还要做两件事

管理员把你加进名单后，会给你**两个邀请**，必须你**亲自接受**，否则名单不生效：

### 1. 接受 Facebook 应用邀请

打开 Facebook 的**通知**，找到来自该应用的角色邀请，点**接受**。

### 2. 接受 Instagram 测试人员邀请

1. 打开 Instagram App → **☰ → 设置和隐私**
2. 找到 **网站许可** / **应用和网站**（不同版本叫法不同）
3. 在**测试人员邀请**里找到该应用，点**接受**

:::caution[这一步最容易被漏掉]
"管理员说加过了，但我还是绑不上" —— 九成是**邀请没接受**。
邀请在 Facebook 通知和 Instagram 设置里是**两个独立的地方**，都要点。
:::

## 自查表

发给管理员之前逐条打勾：

- [ ] Facebook 个人主页链接能在浏览器里**打开**
- [ ] 提供了 Facebook **用户名和数字 ID 两项**
- [ ] 我在要发帖的 Facebook 主页里是**管理员**
- [ ] Instagram 已切换为**专业号**（能看到「洞察」入口）
- [ ] Instagram 已**关联**到那个 Facebook 主页
- [ ] 我**没有**把任何密码写进这张表
- [ ] 管理员加完名单后，我会去 Facebook 通知和 Instagram 设置里**各接受一次邀请**
