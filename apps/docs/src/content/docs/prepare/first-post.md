---

:::tip[这一页的目标]
你已经拿到控制台的登录邮箱和密码。这一页带你**一步不落**地发出第一条帖子。
全程约 15 分钟，不需要任何技术背景。
:::

如果你还没拿到登录账号，先回到 [接入前准备总览](/prepare/checklist/)。

## 第 1 步：登录

1. 用浏览器打开管理员给你的控制台地址
2. 输入**邮箱**和**密码**，登录

登录后看到的第一页是 **总览**，左侧是导航栏。

:::note[看不到某些菜单是正常的]
「路由矩阵」「Prompt 管理」「设置」**只有管理员**能看到。你是运营就看不到这三项，不是出 bug。
:::

## 第 2 步：绑定你的社媒账号

1. 左侧点 **账号健康**
2. 右上角先在下拉框选平台：**X / Instagram / Facebook**
3. 点 **绑定新账号**
4. 页面会跳到该平台的官方授权页 —— 用**你自己的账号**登录并同意授权
5. 授权完成后自动跳回控制台，看到绿色提示：

   > 账号授权完成！该账号已归属于你，市场归属请联系管理员设置。

6. **每个平台重复一次**（要发三个平台就绑三次）

### 绑不上号怎么办

| 看到什么 | 意思 | 怎么办 |
| --- | --- | --- |
| 「生成授权链接失败」 | Postiz 侧配置缺失 | 找管理员，是 `POSTIZ_JWT_SECRET` 没配 |
| 跳转后平台报权限错误 | 你不在应用授权名单里 | 回到 [信息清单](/prepare/account-info/)，确认信息已交且**邀请已接受** |
| IG 授权后选不到账号 | IG 不是专业号或没关联 FB 主页 | 见 [IG 切专业号](/prepare/account-info/#instagram-切换为专业号) |
| 账号卡片显示**失联** | Postiz 侧已没有这个账号 | 找管理员点「立即同步」，或重新绑定 |

:::caution[绑完还差一步]
绑定成功后，账号还**没有「市场」标记**，也**还没进路由矩阵**。
这两项只有管理员能配 —— 通知管理员："我已绑好 X/IG/FB，请设置市场为 `id` 并配置路由。"
不配也能用「撰写发布」手动发帖，但**自动生成的内容不会路由到你的账号**。
:::

## 第 3 步（可选）：先摸清系统是不是"真发"

在发第一条之前，先确认当前是**演练模式**还是**真发模式**。

打开 **撰写发布** 页，如果顶部有这条黄色横幅：

> ⚠️ **当前为 DRY_RUN 模式**
> 发布将在 Postiz 侧生成草稿（Draft），不会直接推送至社媒正式外网。

说明现在是**演练模式**，随便点都不会真的发到外网 —— 适合练手。

**没有这条横幅 = 真发模式，点下去就发到公网了。** 第一次操作强烈建议让管理员先切到演练模式。

## 第 4 步：发出第一条帖子（手动撰写）

这是最直观的入口：自己写文案、自己传图、直接发。

进入左侧 **撰写发布**，页面标题是 `Create Post`，左右两栏。

### 4.1 写文案（左栏 content 区）

在大输入框里打字，占位提示是 `what's on your mind...`。
右下角实时显示**字符数**。

### 4.2 上传配图（左栏 media 区）

有**两个上传位**，按你要发的平台传：

| 上传位 | 给谁用 | 尺寸 |
| --- | --- | --- |
| **+ Add 4:5 media** | Instagram | 1080 × 1350 |
| **+ Add 16:9 media** | Facebook 和 X（共用一张） | 1200 × 675 |

支持 JPEG / PNG / WebP。上传后会显示缩略图、文件名和实际像素，点垃圾桶图标可移除。

:::note[图裁得不对？先去媒体工具试]
手头只有 16:9 的横图但要发 Instagram？先去 [媒体工具](/console/media-tools/) 看转成 4:5 是什么效果，
确认主体没被裁掉再回来上传。
:::

### 4.3 选账号（右栏 platforms 区）

点账号方块选中，选中后边框变粗并出现对勾。右上角显示「已选 N 个」。

**看不到任何账号**会显示「还没有可用账号」和一个跳去账号健康的按钮 —— 说明第 2 步还没做完，
或者管理员还没把账号授权给你。

### 4.4 核对预览（右栏中部）

右栏中间是**实时预览**，按你选的平台分标签页，**在你浏览器本地**模拟三个平台的帖子长相。

- 包含头像昵称、文案排版、图片构图、平台图标、排期时间
- 文案超出平台展示阈值时，标签上会显示超出多少字符（X 是 280，即时间线折叠处）
- **不发任何网络请求**，纯预览

### 4.5 选择发布方式（右栏 publishing 区）

两个按钮切换：

| 模式 | 说明 |
| --- | --- |
| **Schedule** | 排期发布。展开后填 `date & time` 和 `timezone`，右上角会显示换算后的 UTC 时间 |
| **Now** | 立即提交发布 |

### 4.6 提交

底部大按钮，文字会跟着模式变：**`Schedule Post`** 或 **`Publish Now`**。

:::tip[按钮是灰的？看它下面]
按钮禁用时，**下方会用橙色字写明原因**，不用猜：

| 提示 | 怎么解 |
| --- | --- |
| 请选择至少一个发布账号 | 在 platforms 区点选账号 |
| 请输入内容 | 文案还是空的 |
| 已包含 Instagram 账号，请上传 4:5 图片 | IG 必须有图，传 4:5 那个位 |
| 已包含 Facebook 或 X 账号，请上传 16:9 图片 | 传 16:9 那个位 |
| 请设置排期日期和时间 | Schedule 模式下没填时间 |
| 排期时间必须晚于当前时间 | 时间填到过去了，重填 |
:::

## 第 5 步：确认发出去了

提交成功后内容进入发布流水线。去 **发布记录** 页看结果：

| 状态 | 意思 | 你要做什么 |
| --- | --- | --- |
| 队列中 | 排队等执行 | 等 |
| 发布中 | 正在调平台接口 | 等 |
| 已提交 | Postiz 已受理 | **注意：不等于社媒一定发成功**，见下 |
| 失败 | 发布失败，表格里有失败原因 | 点 **重试** |
| 待对账 | 结果未知（超时/中断） | 去平台**亲眼确认**，再点「确认已发送」或「确认未发送」 |

:::caution[「已提交」≠ 帖子已经在平台上]
「已提交」只表示 Postiz 收下了任务。平台侧仍可能投递失败。
系统每 30 分钟自动回读一次平台状态，把投递失败的自动退回**失败**并解锁重试。
所以第一次发布后，**过半小时再回来看一眼**这一页。
:::

**演练模式（DRY_RUN）下**，帖子只会在 Postiz 里生成草稿，社媒上看不到 —— 这是预期行为，不是失败。

## 第 6 步：了解另一条路 —— 审核自动生成的内容

手动撰写是"你自己写"。系统的主线其实是**自动生成 + 你来审核**：

```
Notion 勾选 / WikiFX 采用 / HTTP 推送
        ↓
   系统自动用 LLM 生成各平台文案
        ↓
   进入「审核工作台」← 你在这里把关
        ↓
   点「通过并发布」→ 按路由矩阵自动发到对应账号
```

日常主要工作就是在 **审核工作台** 里：

1. 左侧看**原文**，右侧看**各平台生成稿**
2. 文案和配图都能**直接改**
3. 三个按钮：**通过并发布** / **仅保存修改** / **驳回**

完整说明见 [内容队列与审核](/console/queue-review/)。

:::note[两条路的区别]
| | 手动撰写 | 自动生成 |
| --- | --- | --- |
| 文案谁写 | 你 | LLM |
| 走不走审核工作台 | **不走**（提交即已通过） | 走 |
| 发到哪个账号 | 你自己勾选 | 按路由矩阵自动决定 |
| 在内容队列里的来源 | 手动撰写 | Notion / WikiFX 热点 / HTTP 推送 |
:::

## 遇到问题按这个顺序找

| 症状 | 先看哪里 |
| --- | --- |
| 登录不上 | 找管理员确认账号是否已创建、密码是否正确 |
| 看不到账号 / 看不到内容 | 你没被分配账号。见 [账号与路由 · 用户授权模型](/console/accounts-routing/#用户授权模型) |
| 绑号失败 | [信息清单](/prepare/account-info/) 自查表逐条核对 |
| 帖子发了但同事刷不到 | Meta 应用还在开发模式，找管理员。见 [Meta 准备](/prepare/meta-developer/#开发模式-vs-上线模式) |
| 系统说已发布但平台上没有 | 等 30 分钟自动对账，或去 [发布记录](/console/records-calendar/) 看是否回退为失败 |
| 发布按钮点不动 | 看按钮下方的橙色提示文字 |
| 生成的文案质量不行 | 属 Prompt 调整范畴，找管理员。见 [Prompt 与设置](/console/prompts-settings/) |
