## 为什么不能直接登录就发帖

系统自己**不直接连**社媒平台。真正把帖子推到 X / Instagram / Facebook 的是一个叫 **Postiz** 的发布中台，
而 Postiz 要代你发帖，必须先拿到平台官方的**授权**。

```
你（控制台）→ 本系统 → Postiz → 平台官方 API → X / Instagram / Facebook
                                    ↑
                          这一步需要「平台开发者应用」+「你的账号被授权」
```

平台（尤其是 Meta）对"第三方程序代发帖"管得很严。所以在你能发出第一条帖子之前，
必须先完成两件与代码无关的事：

1. **管理员侧**：在各平台注册开发者应用，把凭据配进 Postiz（一次性，全团队共用）
2. **你这一侧**：把你的账号加入这个应用的授权名单，然后在控制台点「绑定新账号」

:::caution[最容易卡住的地方]
Meta（Facebook / Instagram）的开发者应用在**开发模式**下，**只有被加入应用角色名单的账号**才能授权成功、
帖子才对外可见。这就是为什么需要**你把 Facebook 主页链接和数字 ID 发给管理员** —— 管理员据此把你加进名单。
不做这一步，点「绑定新账号」会失败，或者发出的帖子只有你自己能看到。
:::

## 准备清单（按顺序）

| # | 要做的事 | 归谁办 | 一次性还是每人一次 | 详细步骤 |
| --- | --- | --- | --- | --- |
| 1 | 注册 Meta 开发者账号、创建应用、配好凭据 | 管理员 | 一次性 | [Meta 开发者准备](/prepare/meta-developer/) |
| 2 | 注册 X 开发者账号、创建应用、配好凭据 | 管理员 | 一次性 | [X 开发者准备](/prepare/x-developer/) |
| 3 | 把你的 Facebook 账号加入应用授权名单 | 管理员（需你提供信息） | **每人一次** | [提交给管理员的信息清单](/prepare/account-info/) |
| 4 | Instagram 切换为**专业号**并关联 Facebook 主页 | 你自己 | **每个 IG 账号一次** | [提交给管理员的信息清单](/prepare/account-info/) |
| 5 | 在 Instagram App 里**接受**测试人员邀请 | 你自己 | **每个 IG 账号一次** | [提交给管理员的信息清单](/prepare/account-info/) |
| 6 | 管理员给你开控制台登录账号 | 管理员 | **每人一次** | [Prompt 与设置 · 用户管理](/console/prompts-settings/#用户管理) |
| 7 | 登录控制台 → 「账号健康」→ 绑定新账号 | 你自己 | 每个社媒账号一次 | [账号与路由](/console/accounts-routing/) |
| 8 | 管理员给账号设「市场」并配路由矩阵 | 管理员 | 每个账号一次 | [账号与路由](/console/accounts-routing/#路由矩阵) |

:::note[第 1、2 步已经做过了？]
这两步是**整个团队共用一次**的。如果系统已经在用了，这两步一定已经完成，
你只需要从**第 3 步**开始 —— 也就是把信息发给管理员。
:::

## 你需要准备的东西

在找管理员之前，先把这些手上备齐：

- [ ] 一个**能正常登录**的 Facebook 个人账号（用来授权，不是新注册的空号）
- [ ] 要发帖的 **Facebook 主页**（Page），且你在主页里是管理员
- [ ] 要发帖的 **Instagram 账号**，且已切换为**专业号**（商务或创作者）
- [ ] 要发帖的 **X 账号**，记得住密码（授权时要登录）
- [ ] 一个**工作邮箱**（管理员给你开控制台账号用）

:::danger[不要做的事]
- **不要**把社媒账号的**密码**发给任何人，包括管理员。整个流程只需要主页链接和 ID，永远不需要密码
- **不要**自己去注册新的 Meta 开发者应用。用团队统一的那一个，否则授权对不上
:::

## 办完怎么验收

按顺序确认这几条，全部打勾才算准备就绪：

| 验收项 | 怎么看 | 没通过怎么办 |
| --- | --- | --- |
| 能登录控制台 | 打开控制台地址，用管理员给的邮箱密码登录成功 | 找管理员确认账号是否已创建 |
| 「账号健康」页有你的账号 | 左侧导航「账号健康」，能看到账号卡片且状态是**正常** | 见下方两行 |
| 绑定没报错 | 点「绑定新账号」后跳转平台授权页，授权完回到控制台看到成功提示 | 授权页报错 → 你没被加进应用名单，回到第 3 步 |
| 帖子对外可见 | 用**别人的手机**（不登录你的账号）看能不能刷到测试帖 | 只有自己能看到 → 应用还在开发模式，找管理员 |
| 「撰写发布」能选到账号 | 「撰写发布」页右栏 platforms 区能看到账号方块 | 看不到 → 管理员还没把账号授权给你，找管理员 |
