不经过 LLM 生成的手动撰写入口：自己写文案、自己传图、选择已授权账号后直接发布。

## 操作流程

1. 在「content」区输入文案（页面右下角实时显示字符数）
2. 按平台要求上传配图：
   - **Instagram** 需要 4:5 图片（1080×1350），上传时服务端自动做 4:5 合规转换
   - **Facebook / X** 共享 16:9 图片（1200×675）
3. 在「platforms」区勾选目标账号（只能看到自己被授权的账号）
4. 在「publishing」区选择发布方式：
   - **Schedule**：设置日期时间与时区，按排期发布
   - **Now**：立即提交 Postiz 发布
5. 点击主按钮提交

## 本地帖子预览

页面右栏提供实时预览：根据当前文案、配图与所选账号，**在浏览器本地**模拟三个平台的帖子效果，不发起任何网络请求。

- 按已选平台切换标签页（X / Instagram / Facebook）
- 预览包含：账号头像与昵称、文案排版、图片构图（IG 4:5 转换效果以 CSS 近似）、平台交互图标、排期时间
- 文案超过平台阈值时在标签上显示超出字符数（X 为 280）
- 预览仅作效果参考；实际发布内容以发布结果为准

## 提交后的状态

提交成功即进入发布流水线（`PUBLISHING` → 各平台子任务）。可在「发布记录」页跟踪每个平台的实际投递结果。
