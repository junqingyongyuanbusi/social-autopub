title: 撰写发布
description: 手动撰写文案、上传配图、本地预览与排期发布
---

不经过 LLM 的手动发帖入口：自己写文案、自己传图、勾选账号直接发。
页面标题是 `Create Post`，左右两栏布局。

:::note[和自动生成的区别]
手动撰写的内容**不进审核工作台**（提交即视为已通过），也**不走路由矩阵**（账号由你勾选）。
在内容队列里，它的来源显示为「手动撰写」。
:::

## 先看顶部有没有黄色横幅

如果页面顶部有这条：

> ⚠️ **当前为 DRY_RUN 模式**
> 发布将在 Postiz 侧生成草稿（Draft），不会直接推送至社媒正式外网。

说明当前是**演练模式**，发出去只会在 Postiz 里生成草稿，社媒上看不到 —— 适合练手。
**没有这条横幅就是真发模式，点下去直接上公网。**

## 左栏：content 与 media

### 1. 写文案（content 区）

在大输入框打字，占位提示 `what's on your mind...`，右下角实时显示**字符数**。

### 2. 上传配图（media 区）

两个上传位，按目标平台传：

| 上传位 | 给谁用 | 输出尺寸 |
| --- | --- | --- |
| **+ Add 4:5 media** | Instagram | 1080 × 1350 |
| **+ Add 16:9 media** | Facebook 和 X（**共用一张**） | 1200 × 675 |

- 支持格式：**JPEG / PNG / WebP**
- 上传后显示缩略图、文件名和实际像素
- 点垃圾桶图标移除
- 当前选中的平台**需要**哪个位，那个位会带高亮边框提示

:::tip[Instagram 的 4:5 转换]
上传给 Instagram 的图，服务端会自动做 4:5 合规转换。
担心主体被裁掉，先去 [媒体工具](/console/media-tools/) 看转换效果。
:::

## 右栏：platforms、预览与 publishing

### 3. 选账号（platforms 区）

点账号方块选中，选中后边框加粗并出现对勾，右上角显示「已选 N 个」。
方块上显示账号名、平台和市场（如 `Instagram · id`）。

**没有任何账号**时显示「还没有可用账号」和「前往账号健康绑定」按钮 —— 说明：

- 你还没绑号 → 见 [账号与路由](/console/accounts-routing/#绑定新账号所有登录用户都能做)
- 或管理员还没把账号授权给你 → 见 [用户授权模型](/console/accounts-routing/#用户授权模型)

### 4. 核对本地预览

右栏中部是**实时预览**：根据当前文案、配图和所选账号，**在你的浏览器本地**模拟三个平台的帖子效果，
**不发起任何网络请求**。

- 按已选平台切换标签页（X / Instagram / Facebook）
- 预览包含：账号头像昵称、文案排版、图片构图（IG 的 4:5 转换用 CSS 近似）、平台交互图标、排期时间
- 文案超过平台展示阈值时，**标签上显示超出的字符数**（X 是 280，即时间线折叠处；发布上限另计）

:::note[预览是参考，不是保证]
预览用 CSS 近似平台渲染，实际发布效果以发布结果为准。它的用途是**提前发现明显问题**
（文案太长被折叠、图片主体被裁），而不是像素级还原。
:::

### 5. 选发布方式（publishing 区）

两个分段按钮：

| 模式 | 操作 |
| --- | --- |
| **Schedule** | 展开 `date & time` 和 `timezone` 两个输入框。填完后右上角显示换算后的 **UTC** 时间，可以核对 |
| **Now** | 立即提交 |

### 6. 提交

底部大按钮，文字跟模式变：**`Schedule Post`** 或 **`Publish Now`**。

:::tip[按钮是灰的？看它下面的橙色文字]
按钮禁用时会明确写出原因，不用猜：

| 提示 | 怎么解 |
| --- | --- |
| 正在加载可选账号… | 等一下 |
| 请选择至少一个发布账号 | 在 platforms 区点选 |
| 请输入内容 | 文案是空的 |
| 已包含 Instagram 账号，请上传 4:5 图片 | Instagram 必须有图 |
| 已包含 Facebook 或 X 账号，请上传 16:9 图片 | 传 16:9 那个位 |
| 请设置排期日期和时间 | Schedule 模式没填时间 |
| 排期时间必须晚于当前时间 | 时间填到过去了 |
:::

## 提交之后

提交成功即进入发布流水线（`PUBLISHING` → 按平台拆分子任务）。

去 [发布记录](/console/records-calendar/) 跟踪每个平台的实际投递结果。
排期发布的内容会出现在 [发布日历](/console/records-calendar/#发布日历) 里。

:::caution[「已提交」不等于帖子已在平台上]
「已提交」只表示 Postiz 受理了任务。系统每 30 分钟回读平台状态，
投递失败的会自动退回**失败**并解锁重试。第一次发布后**过半小时再看一眼**发布记录。
:::
