## 发布记录

按子任务（内容 × 平台 × 账号）展示全部发布流水：

| 状态 | 含义 | 可执行操作 |
| --- | --- | --- |
| 队列中 | 已入队等待执行 | - |
| 发布中 | worker 正在调用 Postiz | - |
| 已提交 | Postiz 已受理 | - |
| 失败 | 发布失败并记录了原因 | **重试** |
| 待对账 | 结果未知（响应超时或中断） | **确认已发送** / **确认未发送** |

操作员只能看到自己账号相关的发布任务。

## 投递对账说明

「已提交」表示 Postiz 受理了帖子，但社媒平台最终投递仍可能失败。系统每 30 分钟自动回读 Postiz 状态：

- 投递失败（`state=ERROR`）的帖子会被自动回退为**失败**并解锁重试
- 投递成功不受影响

## 发布日历

按日期分组展示已排期与近期已发布的内容（最新日期在最上）：

- 显示时间、语言与状态
- Schedule 模式提交的内容在排期前会出现在这里
