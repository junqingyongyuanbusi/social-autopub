看账号涨粉、帖子曝光和互动表现。数据是**本地快照**，页面不直接请求外部服务。

## 数据从哪来

后台每 **30 分钟**自动从 Postiz 的 analytics 端点采集（账号级 + 帖子级）入库。

- 采集指标包含曝光、点赞、评论、转推、引用、收藏等（**因平台而异**，不是每个平台都有全部指标）
- 帖子级只覆盖**经本系统发布**的帖子
- 采集受 Postiz 限流保护约束，采用错峰与预算封顶策略

## 页面怎么用

### 1. 选时间窗口

顶部切换 **7 / 30 / 90 天**。窗口影响下面所有区块的统计范围。

### 2. 核心指标卡片

显示最新值和**窗口内环比**（粉丝数、曝光量、互动量等）。

:::note[显示「无基线」是什么意思]
窗口起点没有对应快照，算不出环比。刚接入的账号或刚拉长窗口时会出现，
**等下一个采集周期积累够数据**就有了，不是故障。
:::

### 3. 趋势图

按日折线图，可切换要看的指标。

### 4. 账号明细

每个账号的分指标数值与环比，用来横向比较账号表现。

### 5. 帖子表现

表格列：**标题 / 平台 / 发布时间 / 指标**。找出表现好的帖子，反过来指导选题和文案。

## 手动同步

- **进入页面时自动触发一次**后台同步（带 **3 分钟冷却**防抖，频繁刷新不会重复打上游）
- 也可以点 **刷新** 按钮手动触发
- 同步在后台执行，**不阻塞页面加载** —— 点完等一会儿再刷新页面看新数据

:::tip[刚发的帖子看不到数据]
正常。平台自己统计指标就有延迟，加上系统 30 分钟一次的采集周期，
**新帖子通常要等 1 小时以上**才有数据。
:::

## 你能看到多少数据

- **管理员**：全部账号
- **运营**：只看被分配的账号

见 [用户授权模型](/console/accounts-routing/#用户授权模型)。

## 数据对不上怎么排查

| 现象 | 可能原因 |
| --- | --- |
| 某账号完全没数据 | 账号刚绑定，还没到采集周期；或该平台账号计划无分析权限 |
| X 账号没数据 | X 免费层级可能不含分析权限，管理员可能已设 `DISABLE_X_ANALYTICS=true` |
| 数字比平台后台少 | 采集有周期延迟；且只统计经本系统发布的帖子 |
| 全部显示「无基线」 | 窗口太长，早期快照还没积累够 |
