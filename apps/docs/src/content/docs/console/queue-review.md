这两页是**日常工作量最大**的地方：内容队列用来"找内容"，审核工作台用来"放行内容"。

## 内容队列

按四个维度筛选**全部内容**（不管什么状态、什么来源）。

### 筛选器怎么用

| 筛选项 | 可选值 |
| --- | --- |
| **状态** | 全部状态 / 待生成 / 生成中 / 待审核 / 已通过 / 已发布 / 失败 / 已驳回 |
| **语言** | 如 `en`、`ja`、`id` |
| **内容类型** | 全部类型 / 新闻 / 教育 / 测评 / 曝光 |
| **来源** | 全部来源 / Notion / WikiFX 热点 / HTTP 推送 / 手动撰写 |

表格列出标题、语言、类型、状态等，点行进入内容详情。

:::tip[从总览一键跳过来]
[总览](/console/dashboard/) 页的状态计数卡片是可点的，点「待审核」会直接带着筛选条件跳到这一页。
:::

### 你能看到多少内容

- **管理员**：全部
- **运营**：只能看到**自己账号覆盖语言**的内容，以及**自己账号关联的手动撰写**内容

看不到内容通常是账号还没被授权 —— 见 [用户授权模型](/console/accounts-routing/#用户授权模型)。

## 审核工作台

**只展示 `REVIEW`（待审核）状态的内容。** 点进详情后是左右两栏。

### 界面构成

| 位置 | 内容 |
| --- | --- |
| **左侧** | **来源信息** —— Notion / WikiFX 原文、热度指标（国家、地区等）与原文链接 |
| **右侧** | **各平台预览卡** —— 每个平台一张，文案与配图 URL **都可以直接编辑**；系统发布尾注为只读展示 |
| **底部** | 三个操作按钮 |

### 三个按钮怎么选

| 按钮 | 做什么 | 需要什么权限 |
| --- | --- | --- |
| **通过并发布** | 保存你的修改 **并** 立即按路由拆分发布任务 | `canPublish` |
| **仅保存修改** | 只存草稿，内容**留在待审核**，稍后再处理 | `canEdit` |
| **驳回** | 内容转为 `REJECTED`，不再发布 | `canReview` |

点击后按钮变「处理中…」，结果以页面上的提示条显示（绿色成功 / 红色失败）。

:::caution[Instagram 无图会被拦下来]
Instagram 发布必须有图。如果 IG 平台卡没有配图，点「通过并发布」会**在通过前拦截并提示**，
不会让你把一个必然失败的任务发出去。补上配图 URL 再通过。
:::

### 编辑生成稿的要点

- **文案**：直接在文本框里改。改完记得点「通过并发布」或「仅保存修改」，否则不保存
- **配图 URL**：可替换。要把横图转成 IG 的 4:5，先去 [媒体工具](/console/media-tools/) 处理
- **发布尾注**：系统按内容类型与语言自动追加的 CTA，**只读**，不能改

### 哪些内容不会出现在这里

| 内容 | 原因 | 去哪里看 |
| --- | --- | --- |
| **手动撰写**的内容 | 创建即 `APPROVED`，跳过审核 | [内容队列](#内容队列)筛「手动撰写」进详情 |
| 已通过 / 已发布 / 已驳回的内容 | 不再是 `REVIEW` 状态 | 同上 |

### 审核通过之后

按**路由矩阵**拆分为发布子任务（内容 × 平台 × 账号），进入发布流水线。

- 任何子任务都不会重复发布同一内容（幂等保护）
- 路由在通过的那一刻**快照**到内容上，之后改路由配置不影响它
- 去 [发布记录](/console/records-calendar/) 看每个子任务的投递结果

:::caution[通过后没生成发布任务]
说明**路由矩阵匹配不到规则**。检查该内容的语言与类型，在
[路由矩阵](/console/accounts-routing/#路由矩阵)里确认有对应的启用规则，且账号「市场」已设置。
:::

## 强制审核的两类内容

即使系统开了 `AUTO_PUBLISH=true`（生成后免审直发），下面两类内容**依然强制进入审核工作台**：

- **WikiFX 热点**采用的内容
- **历史重生成**任务
