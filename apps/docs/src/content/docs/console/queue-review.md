## 内容队列

按状态、语言、内容类型、来源四个维度筛选全部内容：

| 筛选项 | 说明 |
| --- | --- |
| 状态 | 待生成 / 生成中 / 待审核 / 已通过 / 已发布 / 失败 / 已驳回 |
| 语言 | 如 `en`、`ja` |
| 内容类型 | 新闻 / 教育 / 测评 / 曝光 / 手动撰写 |
| 来源 | Notion / WikiFX 热点 / HTTP 推送 / 手动撰写 |

操作员只看到自己账号覆盖语言的内容，以及自己账号关联的手动撰写内容。

## 审核工作台

仅展示 `REVIEW` 状态的内容。点击进入详情后：

- 左侧是**来源信息**（Notion / WikiFX 原文、指标与链接）
- 右侧是**各平台预览卡**：文案与配图 URL 均可编辑，系统发布尾注只读展示
- 底部三个操作：**通过并发布** / **仅保存修改** / **驳回**

### 权限与校验

- 编辑需要目标账号的 `canEdit`，通过需要 `canPublish`，驳回需要 `canReview`
- Instagram 无图会在通过前拦截提示（发布必然失败）
- 手动撰写的内容**不会出现在审核工作台**（创建即 `APPROVED`），从内容队列进入详情查看

### 审核后

通过后按路由矩阵拆分为发布子任务；任何子任务都不会重复发布同一内容。
