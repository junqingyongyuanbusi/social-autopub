登录后的默认落地页，用于快速判断系统健康度。

## 界面构成

- **状态计数卡片**：待审核 / 生成中 / 发布中 / 已发布 / 失败的实时数量，点击卡片直接跳转到内容队列的对应筛选
- **近 7 日各平台发布**：按平台拆分已提交、失败、队列中的任务数
- **最近失败**：列出最近的发布失败任务与错误原因，可跳转发布记录页处理

## 常见操作

| 想做什么 | 去哪里 |
| --- | --- |
| 处理积压的待审核内容 | 点「待审核」卡片 → 审核工作台 |
| 排查发布失败 | 「最近失败」列表 → 发布记录页重试 |
| 看整体发布趋势 | 左侧导航「数据分析」 |
