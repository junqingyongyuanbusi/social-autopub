登录后的默认落地页。**每天上班先看这一页**，30 秒判断系统是否正常、有什么要处理。

## 界面构成

### 状态计数卡片

实时显示各状态的内容数量：**待审核 / 生成中 / 发布中 / 已发布 / 失败**。

:::tip[卡片可以点]
点任意卡片会跳到 [内容队列](/console/queue-review/#内容队列)，**并自动带上对应筛选条件**。
处理积压时不用自己去设筛选器。
:::

### 近 7 日各平台发布

按平台（X / Instagram / Facebook）拆分**已提交、失败、队列中**的任务数，看趋势和平台间差异。

### 最近失败

列出最近的发布失败任务和**错误原因**，可跳到发布记录页处理。

## 日常巡检顺序

按这个顺序扫一遍，有异常再深入：

| 看什么 | 正常 | 不正常要做什么 |
| --- | --- | --- |
| **失败**计数 | 0 或很低 | 点「最近失败」看原因，去[发布记录](/console/records-calendar/)重试 |
| **待审核**计数 | 你能当天处理完的量 | 点卡片 → 去[审核工作台](/console/queue-review/#审核工作台)清积压 |
| **生成中**计数 | 几分钟内会降下去 | 长时间不动 = 生成卡住，找管理员查 LLM 配额 |
| **发布中**计数 | 几分钟内会降下去 | 长时间不动 = 发布卡住，找管理员查 Postiz 状态 |
| 近 7 日趋势 | 与排期计划相符 | 某平台突然为 0 → 查该平台账号是否失联 |

## 常见操作入口

| 想做什么 | 去哪里 |
| --- | --- |
| 处理积压的待审核内容 | 点「待审核」卡片 → 审核工作台 |
| 排查发布失败 | 「最近失败」列表 → 发布记录页重试 |
| 看整体发布趋势与社媒指标 | 左侧导航 → [数据分析](/console/analytics/) |
| 自己写一条帖子 | 左侧导航 → [撰写发布](/console/compose/) |
| 检查账号状态 | 左侧导航 → [账号健康](/console/accounts-routing/) |

:::note[页面数字都是 0]
如果你是运营且所有计数都是 0，很可能是**还没被分配账号** ——
没有账号就看不到任何内容。见 [用户授权模型](/console/accounts-routing/#用户授权模型)。
:::
