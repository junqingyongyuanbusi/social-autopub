## Prompt 管理（仅管理员）

生成指令按版本管理，**已发布版本不可变**：

- 修改 Prompt 会创建一个新版本，而不是覆盖旧版本
- 通过「激活」指针决定当前生效版本，可随时回滚到任意历史版本
- 每个版本记录变更说明与激活时间
- 版本配置包括：系统提示词、生成模板、修订模板、平台规则与类型语气

历史生成记录会关联到当时使用的 Prompt 版本，便于追溯生成质量变化的原因。

## 设置（仅管理员）

### Notion 数据源注册表

登记各 Notion 数据库的 Database ID 与语言/表类型：

- 每条登记对应一个轮询来源，可启用/停用
- 页面展示最近轮询时间
- 删除登记不影响已入库内容

### 数据源监控

轮询失败会记录失败尝试（NotionIngestFailure），可在页面查看与重试。
