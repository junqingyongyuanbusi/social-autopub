## 账号健康（账号台账）

账号是 Postiz integration 的本地镜像，由定时同步维护：

- **立即同步**（仅管理员）：拉取 Postiz 账号列表并更新本地台账
- **绑定新账号**：跳转 Postiz OAuth 授权，完成后自动回填到台账
- 状态标记：正常 / 失联（Postiz 侧已不存在）

### 台账字段（仅管理员可编辑）

| 字段 | 说明 |
| --- | --- |
| 市场 | 与路由矩阵的「语言」同语义，如 `id`、`ja` |
| 负责人 | 账号的运营负责人 |
| 授权用户 | 勾选后可查看并操作该账号（见下） |
| 文本上限 | 仅 X 账号。留空表示自动探测：首次发布超过 280 加权字符的内容时，发布成功即判定为订阅账号（4000），被平台以长度为由拒绝则判定为免费账号（280）。填入数值可手动覆盖探测结果，清空则重新探测 |
| 备注 | 自由文本 |

### 用户授权模型

用户与账号通过授权关系绑定，关联即可见；动作权限按位控制：

| 权限位 | 含义 |
| --- | --- |
| `canEdit` | 编辑生成文案与配图 |
| `canPublish` | 通过审核、重试发布 |
| `canReview` | 驳回内容 |

管理员不受限制；未分配任何账号的操作员看不到内容与热点数据。

## 路由矩阵

配置 `语言 × 内容类型 × 平台 → 账号` 的发布路由：

- 内容类型支持 `*` 通配
- 同一组合可配置多行，`priority` 决定取用顺序（容灾备选）
- 只有启用（`enabled`）的规则参与匹配

路由仅在审核通过时快照到内容上；后续变更不影响已批准的内容。手动撰写内容不走路由。
