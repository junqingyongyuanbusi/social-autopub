## 账号健康（账号台账）

这一页管两件事：**把社媒账号绑进系统**，以及**谁能操作哪个账号**。

账号数据是 Postiz 账号列表的本地镜像，由定时同步维护。

:::caution[绑号之前必须先做平台侧准备]
Meta（Facebook / Instagram）的开发者应用在开发模式下，**只有被加进授权名单的账号**才能绑定成功。
第一次绑号请先读 [接入前准备总览](/prepare/checklist/) 和 [提交给管理员的信息清单](/prepare/account-info/)。
:::

### 绑定新账号（所有登录用户都能做）

1. 右上角下拉框选平台：**X / Instagram / Facebook**
2. 点 **绑定新账号**（按钮会变成「跳转授权中…」）
3. 页面跳到平台官方授权页，用**你自己的账号**登录并同意
4. 自动跳回控制台，看到绿色提示：

   - 你是运营 → 「账号授权完成！该账号已归属于你，市场归属请联系管理员设置。」
   - 你是管理员 → 「账号授权完成！可为新账号「编辑台账」设置市场与授权用户。」

新绑定的账号会**自动授权给发起绑定的那个人**，并把此人设为负责人。

| 报错 | 原因 | 怎么办 |
| --- | --- | --- |
| 「生成授权链接失败，请确认 POSTIZ_JWT_SECRET 配置」 | Postiz 侧密钥没配 | 找管理员 |
| 跳转后平台报权限错误 | 账号不在应用授权名单 | 见 [信息清单](/prepare/account-info/) |
| IG 授权完选不到账号 | IG 不是专业号或未关联 FB 主页 | 见 [IG 切专业号](/prepare/account-info/#instagram-切换为专业号) |

### 立即同步（仅管理员）

点 **立即同步** 拉取 Postiz 账号列表并刷新本地台账。用在：

- 有人在 Postiz 网页端直接绑了号，控制台还没有
- 账号卡片显示**失联**，想确认是不是真的没了

同步失败会提示「同步失败，请确认 Postiz 服务与 API Key 配置」。

### 账号卡片读法

| 显示项 | 含义 |
| --- | --- |
| 右上角 **正常** / **失联** | 失联 = Postiz 侧已不存在这个账号 |
| 市场 | 决定路由匹配的语言，如 `ID`、`JA`。未设置显示「未设置」 |
| 负责人 | 运营负责人 |
| 授权用户 | 能看到并操作此账号的人。没配时显示「仅管理员」 |
| 文本上限（仅 X） | 显示数值或「待探测（首次长文发布时自动判定）」 |
| 上次同步 | 最后一次与 Postiz 对齐的时间 |

### 编辑台账（仅管理员）

点账号卡片里的 **编辑台账**：

| 字段 | 填什么 |
| --- | --- |
| **市场** | 与路由矩阵的「语言」同语义，如 `id`、`ja`。保存时自动转小写 |
| **负责人** | 从用户列表里选 |
| **授权用户** | 勾选谁能看到并操作此账号（可多选） |
| **备注** | 自由文本 |
| **文本上限**（仅 X 账号） | 留空 = 自动探测；填数值 = 手动覆盖；清空 = 重新探测 |

填完点 **保存**。

:::note[文本上限的自动探测逻辑]
留空时，首次发布超过 280 加权字符的内容：

- 发布**成功** → 判定为订阅账号，上限记为 **4000**
- 被平台以长度为由**拒绝** → 判定为免费账号，上限记为 **280**

不确定账号是否有 Premium 订阅时，**留空让系统自己判**比猜一个数字更可靠。
:::

### 删除失联账号（仅管理员）

只有状态为**失联**的账号才会出现删除按钮。删除会：

- 清除本地台账记录
- **同时清除该账号的所有路由规则**
- 不可恢复（会弹确认框）

不影响已发布的历史记录。

## 用户授权模型

用户与账号通过**授权关系**绑定 —— **关联即可见**：

| 权限位 | 允许的动作 |
| --- | --- |
| `canEdit` | 编辑生成文案与配图、采用 WikiFX 热点 |
| `canPublish` | 通过审核、重试发布 |
| `canReview` | 驳回内容 |

- **管理员**不受任何限制，看得到全部账号、内容与数据
- **运营**只能看到被分配的账号，以及这些账号覆盖语言的内容和热点
- **没被分配任何账号的运营**：登录后各页面基本是空的，这是预期行为

:::tip[新人说"页面什么都没有"]
不是 bug。去「账号健康」→ 编辑对应账号台账 → 在**授权用户**里勾上这个人 → 保存。
:::

## 路由矩阵

**仅管理员可见。** 决定自动生成的内容最终发到哪些账号。

规则形式：`语言 × 内容类型 × 平台 → 账号`

### 配置要点

- **内容类型支持 `*` 通配**，匹配全部类型
- 同一组合可配**多行**，`priority` 决定取用顺序（用作容灾备选）
- 只有**启用**（`enabled`）的规则参与匹配
- 规则里的「语言」要与账号台账里的「市场」对得上

### 什么时候生效

路由**只在审核通过的那一刻**快照到内容上（`publishTargets`）。之后：

- 改路由配置**不影响已批准的内容**
- **手动撰写的内容不走路由** —— 目标账号由你在撰写页勾选

:::caution[路由没配 = 自动生成的内容发不出去]
审核通过时如果匹配不到任何路由规则，内容无法拆分出发布任务。
绑完新账号后，务必设「市场」+ 配路由，两步都做完才算接入完成。
:::
