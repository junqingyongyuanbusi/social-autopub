---
title: 热点选题
description: 从 WikiFX 榜单挑选题、手动抓取指定文章、采用进入生成队列
---

从 WikiFX 榜单里筛出值得成稿的选题，**采用**后进入生成流水线。
未采用的热点**不会**创建内容、不调用 LLM —— 所以随便浏览不产生任何成本。

## 页面顶部：状态条读法

打开页面先看这几个指标，判断数据新不新：

| 显示项 | 含义 |
| --- | --- |
| **统计区间** | 当前统计的是最近几个完整自然日 |
| **上游缓存年龄** | 数据距上次从上游拉取过了多久 |
| 缓存状态 | `upstream`（刚从上游拿的）/ `local-fresh`（本地新鲜缓存）/ `local-stale`（上游不可用，用了旧缓存） |

:::note[看到 local-stale 怎么办]
说明上游榜单暂时不可用，页面在用 24 小时内的旧缓存兜底。数据可能不是最新的，
但仍可正常采用。持续出现要找管理员查 `WIKIFX_ARTICLES_API_KEY` 与上游状态。
:::

## 筛选榜单

| 筛选项 | 说明 |
| --- | --- |
| **语言** | 全部语言，或指定单一语言 |
| **国家 / 地区** | 全部，或指定 |
| **搜索框** | 搜索标题、正文或地区（占位提示「搜索标题、正文或地区」） |
| **状态** | 全部状态 / 未采用 / 已采用 |
| **统计天数** | `1`～`3` 个完整自然日 |

列表**保持上游排序**，不做二次排名。

### 表格列读法

| 列 | 内容 |
| --- | --- |
| **选题** | 标题与摘要 |
| **热度指标** | 浏览 / 活跃 / 点击 / 阅读等数值（因数据源而异） |
| **正文 / 首图** | 正文是否可用、有没有首图 |
| **状态** | 未采用 / 已采用 |
| **操作** | 采用按钮 |

### 你能看到多少热点

- **管理员**：全部语言
- **运营**：只能看到**自己账号覆盖语言**的热点

## 采用热点

1. 找到想做的选题，点该行的**采用**
2. 采用成功后状态变为**已采用**，可点链接跳到审核详情

**需要该目标语言的 `canEdit` 权限。**

:::note[采用时发生了什么]
API 会从**可信榜单和内部正文 sidecar 重新解析正文** ——
浏览器提交的标题、正文和图片**不会直接入库**。这是安全设计，防止前端被篡改后注入内容。
:::

### 什么情况下不能采用

| 情况 | 表现 |
| --- | --- |
| 正文为空 | 采用按钮禁用，提示「正文不可用，暂时不能采用」 |
| 已经采用过 | 状态显示已采用，不能重复采用 |
| 没有该语言的 `canEdit` | 采用失败 |

正文为空的文章**只能查看不能采用** —— 没有正文，LLM 生成不出东西。

## 手动抓取指定文章

榜单里没有但你想做的文章，可以直接贴链接抓。

1. 在页面上方的**手动抓取**区，粘贴 WikiFX newsdetail 链接
   - 示例：`https://www.wikifx.com/ja/newsdetail/202608202624732011.html`
   - **只接受白名单域名**：`www.wikifx.com` / `aws-www.wikifx.com`
2. 需要重新抓取时勾上 **强制抓取**
3. 抓取成功后显示正文预览
4. 确认可用，点 **采用并进入队列**（按钮忙时显示「采用中…」）
5. 采用后显示「已采用 · <状态>」和跳去审核详情的链接

:::note[链接不会被转发]
服务端只从 URL 里**提取语言和文章 ID**，原始 URL 不转发给上游。
:::

| 抓取结果 | 含义 |
| --- | --- |
| `ok` | 抓到正文，可以采用 |
| `empty` | 页面存在但正文为空，不能采用 |
| `not_found` | 文章不存在 |
| `blocked` | 被上游拦截 |
| `timeout` | 抓取超时，可勾「强制抓取」重试 |
| `error` | 其他错误 |

不勾「强制抓取」时先读已有正文库，没抓过会返回 `content_not_fetched` —— 这时勾上强制抓取再试。

## 采用之后

WikiFX 内容**即使系统开了 `AUTO_PUBLISH=true` 也强制进入人工审核**。

去 [审核工作台](/console/queue-review/#审核工作台) 把关生成稿：

- 左侧能看到 WikiFX 原文、国家地区与热度指标
- 有效首图会自动进入生成稿的媒体
