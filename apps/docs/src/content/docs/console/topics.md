---
title: 热点选题
description: WikiFX 热点榜单阅读与采用
---

从 WikiFX 榜单中筛选值得成稿的选题，采用后进入生成流水线。

## 榜单读取

- 统计最近 `1..3` 个完整自然日的热点文章，支持按 Top 数量筛选
- 列表保持上游排序；页面展示统计区间、缓存状态（`upstream` / `local-fresh` / `local-stale`）与数据质量提示
- 可见性：操作员只能看到自己账号覆盖语言的热点，管理员可见全部

## 采用与手动抓取

- **采用**：要求目标语言的 `canEdit` 权限。采用时 API 会从可信榜单与内部正文 sidecar 重新解析正文，浏览器提交的内容不会直接入库
- **手动抓取**：粘贴 WikiFX newsdetail 链接（仅 `www.wikifx.com` / `aws-www.wikifx.com` 白名单域名），抓取正文预览后可采用。服务端只提取语言与文章 ID，原始 URL 不转发给上游

## 边界

- 正文为空的文章只展示、不允许采用
- WikiFX 内容即使在 `AUTO_PUBLISH=true` 下也**强制进入人工审核**
- 未采用的热点不会创建内容、不调用 LLM
