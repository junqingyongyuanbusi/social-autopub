---

Instagram Feed 要求 **4:5 竖图（1080 × 1350）**，但素材通常是 16:9 横图。
这一页让你**发布之前**就看清转换效果，避免图片主体被裁掉。

## 什么时候用

- 手头只有横图，但要发 Instagram
- 想确认转换后**人物的头 / 文字标题**会不会被切掉
- 需要把转换结果下载下来，人工微调后再上传

:::note[不用这一页也能发]
「撰写发布」和「审核工作台」在发布时会**自动**做 4:5 合规转换，不来这页也能发。
这页的价值是**提前看结果**，不合适就换图或重新构图，而不是发出去才发现被裁坏了。
:::

## 操作步骤

1. 左侧导航点 **媒体工具**
2. 在输入框粘贴图片 URL（占位提示是 `粘贴 16:9 图片 URL`）
3. 点 **生成预览**（也可以直接按回车）
4. 左右对比：

| 左侧 | 右侧 |
| --- | --- |
| **原图** —— 右上角显示原始像素（如 `1200 × 675`） | **Instagram 4:5** —— 标注「发布输出 1080 × 1350 JPEG」 |

5. 觉得可用，点右上角 **下载预览** 存下来

## 注意事项

- URL 必须是 **http 或 https** 开头。填错会提示「请输入有效的 http(s) 图片 URL」
- 图片必须**公开可访问**。私有链接或已过期的临时链接会提示
  「图片下载或转换失败，请确认 URL 可公开访问且未过期」
- 转换在**服务端**完成，和实际发布用的是同一套逻辑 —— 所以预览就是最终效果

:::tip[头像和标题被裁掉怎么办]
4:5 比 16:9 高、窄，左右两侧必然被裁。解决办法：
1. 换一张**主体居中**的图
2. 下载预览后用图片工具手动调，再回「撰写发布」上传到 **+ Add 4:5 media** 位
:::
